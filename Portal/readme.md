## Portal Clone
### STATUS [FINISHED]

This is a small Portal-inspired game made in Unity.

You can download it on itch.io:
[here](https://cayama0811.itch.io/portal-clone-xbox-360)

### PC

The `PCBuild` folder contains the latest playable PC build.
You can simply open the executable inside the folder to play it.
If you want to build the project yourself, the `PCBuild` folder is also included for convenience.

### Xbox 360

The `XboxBuild` folder contains the latest Xbox 360 build.
To run it on an Xbox 360, copy the build to a storage device supported by your console and place it in the appropriate game/content directory used by your setup.
If you are using Aurora, you may want to rename the folder to something like:

`PortalClone`

so it is displayed with the correct name.

> **Note:** The Xbox 360 build requires a console capable of running unsigned/homebrew software.

### Development

The game was developed using Unity 5.4.1f.
For Xbox 360 development, Unity 5.4.1f and the corresponding Xbox 360 development environment are required.
