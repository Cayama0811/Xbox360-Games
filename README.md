# Xbox360-Games

The source code of the homebrews that I made.

## How to use it

It's very simple: download the repository and open the projects with Unity.
The projects were made with Unity 5.4.1f. Other Unity versions may work, but I have only tested them with 5.4.1f.
If you want to compile them for Xbox 360, you MUST use Unity 5.4.1f with the appropriate Xbox 360 development environment.
If you don't know how to compile Unity projects for Xbox 360, you can search online for documentation about it.
